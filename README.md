# 🏡 Real Estate Price Predictor

An interactive Machine Learning valuation app built with Python, Streamlit, and Scikit-Learn to estimate residential property prices.

🚀 **[Live Demo](https://house-price-predictor.streamlit.app/)**

## ✨ Features

* **Real-time Price Estimation:** Instantly predicts market property values using a `RandomForestRegressor`.
* **Flexible Parameter Controls:** Adjust square footage, bedroom/bathroom counts, age, and location quality score via interactive sliders.
* **Feature Importance Analytics:** Plotly horizontal bar chart displaying which structural factors drive house values the most.

## 🛠️ Tech Stack

* **Frontend / Framework:** Streamlit
* **Machine Learning:** Scikit-Learn
* **Data Processing:** Pandas, NumPy
* **Visualization:** Plotly Express
